# Employee Manager CLI

CLI приложение для управления сотрудниками на Python.

## Возможности

- Добавление сотрудника
- Поиск сотрудника
- Удаление сотрудника
- Добавление бонусов
- Добавление штрафов
- Просмотр итоговой зарплаты
- Хранение данных в JSON

## Технологии

- Python
- OOP
- JSON
- Git & GitHub

## Структура проекта

models.py — классы сотрудников
storage.py — работа с JSON
workers.json — сотрудники
bonus.json — бонусы
fine.json — штрафы
main.py — запуск программы

## Запуск проекта

'''bash
python main.py
'''
